## 🚀 Deploy Your Own

1. Fork this repo
2. Go to [netlify.com](https://netlify.com) → **Add new site → Import from Git**
3. Select this repo → click **Deploy**
4. Update `script.js` with your own [Formspree](https://formspree.io) ID for the contact form
